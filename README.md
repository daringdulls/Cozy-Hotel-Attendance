# Clockwise — Staff Attendance & Payroll

A responsive attendance dashboard for an 8-hour workday, one weekly day off, monthly payroll summaries, and staff signature approval before payroll.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

The app is ready for Vercel. Import this folder as a Vercel project or run `vercel` from this directory.

> This version is a polished front-end prototype. It stores signatures in the current browser. Before using it for real payroll, connect secure authentication and a database with audit logs and role-based access.
